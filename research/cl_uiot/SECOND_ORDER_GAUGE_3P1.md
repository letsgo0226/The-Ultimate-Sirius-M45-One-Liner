# Second-order gauge covariance

Use the pullback exp(epsilon L_X) with contravariant polynomial vector X. For g=eta+epsilon h+epsilon² j, h'=h+L_X eta and j'=j+L_X h+L_X² eta/2. Tensor naturality gives E2'=E2+L_X G1[h], where E2=G1[j]+G2[h]. Thus E2 is invariant on first-order vacuum solutions. Off shell the Lie correction is essential.

The code checks exact polynomial instances including a pure gauge flat metric, an off-shell perturbation and the prior TT backreaction solution. It uses a single generator, not an independent second-order generator or a global finite coordinate map. No physical unification or general gauge fixing is claimed. No merge or deployment.
