# Adaptive reliability with summable failure budgets

For t>=0 allocate e_t=epsilon/2^(t+1). A prefix of T cycles consumes at most epsilon(1-2^-T), leaving epsilon 2^-T. If conditional first-failure hazards are bounded by e_t for every cycle, countable additivity gives probability of any failure <= epsilon. Independence across time is unnecessary; fault propagation, resizing/migration and recovery operations must be included in the hazard guarantee, not assumed away.

For 0<p<0.1 use (10p)^(2^n)/10 <= e_t. A sufficient depth is max(0,ceil(log2(log(10 e_t)/log(10p)))) when e_t<p, otherwise zero. Hence depth is O(log(t+1)) and data qubits 5^n are O((t+1)^log2(5)) for fixed p,epsilon. This is an upper resource bound, not a lower bound on all architectures. For positive p, any fixed finite depth eventually fails this particular shrinking-bound certificate. The code checks finite prefixes under a fixed per-cycle data budget and stops at the first uncertified cycle; its bound then covers only the certified prefix. Exact rational powers can be expensive. No infinite execution, physical migration, noisy operations, permanent storage or hardware independence is demonstrated. No merge or deployment.
