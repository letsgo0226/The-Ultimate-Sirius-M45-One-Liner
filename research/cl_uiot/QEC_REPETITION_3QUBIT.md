# Three-qubit repetition code and Knill-Laflamme audit

Encode |0> as |000> and |1> as |111>. For the error set I,X1,X2,X3, the four syndrome subspaces are mutually orthogonal and span the eight-dimensional space. Therefore V† E_a† E_b V = delta_ab I2, the Knill-Laflamme condition. Recovery followed by decoding has Kraus maps V† X_m for m in {0,1,2,4}; their adjoint products sum to I8. This recovers arbitrary logical states for the stated error family, including coherent linear combinations subject to channel normalization. Code tests exact rational real density matrices, individual flips and probabilistic mixtures. Double flips can cause logical X; phase flips are not corrected. This is not a full quantum error correction code against arbitrary single-qubit errors. No physical hardware, fault-tolerant gates, indefinite storage or hardware independence is demonstrated. No merge or deployment.
