# Minimum sufficient ideal concatenation resources

For independent child-block Pauli noise and ideal recovery, use the monotone upper-bound map F from qec_concatenated_5qubit. Search depths in ascending order within a data-qubit budget B, evaluating F exactly with rational arithmetic. First success is minimum depth and data-qubit count for this bound, not necessarily optimal for the actual channel or across codes. If F(p)>=p, monotonicity implies further iteration cannot decrease the bound. A failed certificate does not establish physical impossibility. For T cycles, a union bound gives mission failure <= T epsilon_step if each cycle's conditional failure probability (given previous success) is bounded by epsilon_step. No independence across cycles is required for that conditional bound. The planner allocates epsilon_mission/T. This assumes a valid per-cycle bound and does not model fault propagation. Data-qubit counts exclude ancillas, operations, time and energy. Exact fractions can grow rapidly; intended for small bounded depths. No perpetual storage or hardware threshold claim. No merge or deployment.
