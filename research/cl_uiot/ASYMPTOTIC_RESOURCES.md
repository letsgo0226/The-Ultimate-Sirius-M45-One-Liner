# Asymptotic minimum resources for the scalar certificate

For F(p)=Pr(Binomial(5,p)>=2), the event that the first two bits fail gives p²<=F(p); union over ten pairs gives F(p)<=10p². Iterating for fixed 0<p<0.1 gives p^(2^n)<=F^n(p)<=(10p)^(2^n)/10. For target e_t=epsilon/[U(t+1)^s], the minimum depth certifying F^n(p)<=e_t is bounded below by log2(log(1/e_t)/log(1/p)) and above by max(0,ceil(log2(log(1/(10e_t))/log(1/(10p))))) for sufficiently large t. Both are log2(log(t+2))+O(1). Consequently N_min=5^n=Theta((log(t+2))^log2(5)). This is a matching bound on the required scalar certificate, NOT a lower bound on actual logical failure or all quantum architectures. F itself is an upper bound on physical logical failure. A tighter decoder/channel analysis might certify fewer qubits. The exact rational implementation returns depth brackets within a user-supplied finite search cap; None means the corresponding crossing was not observed. No physical fault tolerance, infinite execution, optimal schedule or hardware independence is established. No merge or deployment.
