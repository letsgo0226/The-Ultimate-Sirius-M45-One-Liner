# Amplitude damping and zero-entropy fixed point

Let r in [0,1] be survival amplitude and gamma=1-r². Kraus operators E0=diag(1,r), E1=sqrt(1-r²)|0><1| satisfy completeness, hence define CPTP evolution. For real density matrix [[a,b],[b,1-a]], n iterations give excited population (1-a)r^(2n) and coherence b r^n. The same formula holds for complex coherence. Trace distance to ground state is sqrt((1-a)^2 r^(4n)+|b|² r^(2n)). For r<1 the ground state is the unique fixed point and convergence follows; finite-dimensional entropy continuity gives entropy tending to zero. At r=1 the channel is identity. Entropy is not necessarily monotone: an initially pure excited state becomes mixed for 0<r<1. The channel can be realized via a unitary on system and fresh ground-state environment qubits, with environment discarded; repeated use assumes this resource. Global unitary entropy is conserved. No thermodynamic cost bound, physical implementation, or information-preserving reset is claimed. Exact rational tests cover real states and squared trace distance; entropy is floating point. No merge or deployment.
