# GSMEO: stable-set extension by preimages

Define the local stable set within a sufficiently small saddle neighborhood U as the points whose entire forward orbit remains in U and converges to c. The prior local stable graph theorem identifies this germ. Every globally convergent orbit eventually remains in U; conversely every finite preimage of a local stable point converges to c. Hence the global stable set equals the countable union of finite preimages of the local stable set, with no invertibility assumption. Since this local set is forward invariant, these preimages are nested. They need not be smooth manifolds globally because the map can be singular. This identity does not establish that every point outside the five attracting basins converges to a saddle.

The implementation supplies exact rational finite preimage predicate evaluation and interval exclusion: if an enclosing target box contains the desired local stable patch, disjointness of the n-step interval image excludes membership in its n-th preimage. Intersection is checked on the simplex. Non-exclusion is unknown, not membership. No algebraic exact saddle graph membership predicate or complete global stable-set cover is implemented. Tests use rational surrogate targets, not the irrational saddle itself. No merge or deployment.
