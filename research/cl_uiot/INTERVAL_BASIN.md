# GIBCO: rigorous interval basin witnesses

All decoder probability polynomials have nonnegative integer coefficients on the probability simplex. Evaluate each monomial at the componentwise lower and upper endpoints; monotonicity encloses every image of the physical part of the box. Round outward to multiples of 10^-digits and intersect each coordinate with [0,1]. Induction gives a finite-orbit enclosure without rational denominator explosion. A lower probability endpoint above 9/10 certifies convergence to the corresponding deterministic Pauli vertex by the existing identity error bound and Pauli covariance. Alternatively enclose each Bloch coordinate using complementary probability sums; if the squared maximum absolute endpoint is below 2/3, GTREO certifies uniform convergence. These tests are sufficient, never necessary. The split primitive bisects the widest coordinate and discards boxes with empty simplex intersection; it preserves coverage of the original physical subset. No full adaptive cover has been run. A finite cap and interval dependency can leave undecided boxes, especially near critical manifolds. Unknown is not a nonconvergence witness. Tests target containment, basin decisions, finite iteration, and partition coverage; no hardware claims, merge or deployment.
