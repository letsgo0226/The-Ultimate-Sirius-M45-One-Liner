# PCPO: exact pair-sum projection
PCEGCO run 44893193117 measured 131 paired nodes, 66 baseline unknown leaves, versus 32 uniform and 34 unknown with tightening. For a pair of probabilities, its feasible sum is exactly the intersection of its own sum interval with one minus the complementary pair sum interval. Independent interval sums attain every intermediate value. Therefore each affine Bloch coordinate range is exact for the simplex-intersected box; taking absolute ranges yields exact individual magnitude extrema. The resulting Bloch box is not the full joint correlated image. It is used only for sound classification, with probability interval evolution unchanged. No matched experiment for PCPO yet. No merge or deployment.
