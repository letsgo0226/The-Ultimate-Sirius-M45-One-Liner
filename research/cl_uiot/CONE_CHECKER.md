# GCIPVO
The producer exports a binary tree (axis,left,right) or a leaf label. The checker reconstructs every dyadic box from the full root, checks infeasibility or rational magnitude inequalities independently, and rejects missing children. It imports only Fraction, uses the complement-product identity, and clips the global maximum by physicality. The checker verifies the nonnegative sorted tetrahedral cover, not the analytic lemmas linking it to global convergence. JSON roundtrip is tested; the tree is generated at runtime, not yet committed as a standalone JSON artifact. Depth and node limits bound validation. Independent implementation is not external peer review. No merge or deployment.
