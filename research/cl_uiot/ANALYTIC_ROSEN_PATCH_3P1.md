# Analytic Rosen patch: an exactly terminating subclass

For ds²=dt²-dz²-A(u)² dx²-B(u)² dy², u=t-z, the only potentially nonzero Ricci component in null coordinates is R_uu=-A''/A-B''/B. Choose A=1+epsilon u, B=1-epsilon u. Both second derivatives vanish, and both factors are positive on |epsilon u|<1. The metric is exactly vacuum there and is analytic in epsilon with a terminating quadratic series. In fact the Riemann tensor also vanishes for affine scale factors: this is a flat coordinate example, not a nontrivial gravitational wave.

Its first-order TT profile is -2u and its second-order transverse correction is -u². Higher corrections vanish; the existing recursive algorithm chooses zero integration constants, hence reproduces this solution. This is only an exact terminating benchmark, not a general convergence theorem or a proof of nonflat wave convergence. No merge or deployment.
