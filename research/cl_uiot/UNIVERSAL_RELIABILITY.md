# Universal summable reliability resource theorem

For any positive nonincreasing schedule e_t with sum <= epsilon, (t+1)e_t <= epsilon. With fixed 0<p<0.1 and scalar certificate F^n(p)<=e_t, the bound p^(2^n)<=F^n(p) implies n >= log2(log((t+1)/epsilon)/log(1/p)) for sufficiently large t. Hence 5^n=Omega((log(t+2))^log2(5)). Zeta schedules and the exact telescoping schedule e_t=epsilon/[(t+1)(t+2)] attain the matching Theta order by the previous upper certificate. This proves order optimality only among monotone summable budgets in the specified scalar certificate model, not optimal constants or physical architectures. Without monotonicity, sparse larger allocations can violate the pointwise envelope, so this proof does not apply. A finite prefix audit does not certify its unknown continuation.
